需要的软件 手机条件
Linux deploy root
clash等 科学网络
ssh

点击安装

耐心等待安装成功后，使用ssh连接到系统。

apt update
apt install wget
yum install -y wget && wget -O install.sh http://download.bt.cn/install/install_6.0.sh && sh install.sh

在安装环境后直接安装宝塔就行，成功启动到宝塔后可能还有点问题。

安装成功后浏览器连接到宝塔面板，配置一下…这里可能要安装很久。。。

成功后在ssh内操作

sudo usermod -a -G aid_inet,aid_net_raw www
sudo usermod -a -G aid_inet,aid_net_raw mysql

目的是给一下必要的权限

我说的还是很简陋，你也可以直接下载我配置好的镜像，直接启动就能用。
